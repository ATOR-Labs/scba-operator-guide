Custom SCBA Parameters · 01

Turn on Edit Mode & add a row

The editor opens read-only. Switch on editing, then add a new component row.

  1. Click Enable Edit Mode and confirm the prompt.
  2. Pick a component tab, type the name and fill the parameter fields.
  3. Click ADD …. Check the summary of what will be inserted, click Yes.
  4. Enter a source citation and click OK. The row is saved and loaded ready for more edits.
⚠

Every write needs a source citation and is recorded in the audit trail with your name.

Custom SCBA Parameters · 02

Edit an existing row

Change a value on a row that already exists. You see precisely what changes before it commits.

  1. Type the row's ID and click Load for Edit (or click the row in the table).
  2. Change any fields, then click Update Loaded ….
  3. The summary lists each field as old → new. Click Yes.
  4. Cite the source and click OK.
⚠

Only fields shown on the form are written — untouched data is never overwritten.

Custom SCBA Parameters · 03

Remove a row

Delete a parameter row by its ID. The full row is shown so you can be certain.

  1. Enter the ID in … to Remove (or click the row).
  2. Click Remove …. The whole row is shown for review.
  3. Click Yes, then cite the source.
⚠

Deletes are permanent and recorded in the audit trail with your citation.

Custom SCBA Parameters · 04

Set the unit system

Components that carry a unit use a constrained dropdown — you can't enter an invalid unit.

  1. Open the Unit System dropdown.
  2. Pick a unit. Facepiece pressures offer inH2O / mbar; high-pressure tables offer PSI / bar.
Custom SCBA Parameters · 05

Switch between components

Parameters are grouped into six component tabs. Add and edit work the same way in each.

Custom SCBA Parameters · 06

Invalid values are caught

The editor type-checks every field against the database. Nothing is saved until the values fit.

  1. If a numeric field contains text, ADD / Update stops.
  2. A message names the field and shows the expected format.
  3. Fix the field and try again — you'll never be asked to cite a source for a value that can't save.
Database Viewer · Assets · 01

Pick a database

The viewer is read-only. Start by choosing which asset database to browse.

  1. Open the Database: dropdown and pick a database.
  2. If one is missing, click Rescan Server.
  3. Open the Assets tab. The status reads Browsing '…' (read-only).
Database Viewer · Assets · 02

Choose the columns

Show only the columns you care about. Your selection is remembered per user.

  1. Click Columns….
  2. Tick or untick columns, or use Select All / Clear All / Restore Defaults.
  3. Click OK. The grid updates and your layout is saved.
Database Viewer · Assets · 03

Filter by a date range

Find assets due — or tested — within a window of dates.

  1. In Date: choose a date column, e.g. Test Due Date.
  2. Set the between and and dates.
  3. The grid and the row count update immediately.
  4. Choose (No date filter) to clear it.
▶

The date filter and the value filter apply together — e.g. Location is a station and Test Due Date within a window.

Database Viewer · Assets · 04

Filter by a value

Narrow the list to one model, customer, location — any column value.

  1. In Filter by: choose a column such as Location or Model.
  2. Pick a value from the is dropdown.
  3. Choose (No filter) / (All) to clear it.
▶

Combine this with the Date: filter to see, for example, one location's assets due within a date range.

Database Viewer · Assets · 05

Sort the list

Order the grid however helps — for example, by soonest test due.

  1. Choose a column in Sort by:.
  2. Tick Descending to reverse the order.
▶

You can also click a column header in the grid to sort by it.

Database Viewer · Assets · 06

Open a full record

The grid shows a subset of columns; the record popup shows the whole thing.

  1. Double-click any row in the grid.
  2. The record opens with every field, including columns not shown in the grid.
  3. Read or copy any value, then click Close.
Database Viewer · Assets · 07

Print the inventory

Print exactly what's on screen, under a branded report header.

  1. Click Print… to open the preview.
  2. Check the header — database, customer filter, and your name.
  3. Click Print in the preview to send it to a printer or PDF.
▶

The report follows your current column choice, filter and sort — set those first.
