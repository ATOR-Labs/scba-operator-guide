# SCBA Operator Guide

A step-by-step operator guide for the **ATOR Custom SCBA Parameters** application,
covering the two screens operators use most:

- **Custom SCBA Parameters** — add, edit and remove compliance parameter rows
- **Database Viewer · Assets** — browse, filter, sort, inspect and print the asset inventory

Every step plays a short clip recorded from the live application.

## Hosting

This is a static site (plain `index.html` + `gifs/`). It is published with
GitHub Pages from the `main` branch root:

➡️ **https://ator-labs.github.io/scba-operator-guide/**

To run locally, open `index.html` in any browser — no build step or server needed.

## Notes

- The clips were recorded against **test-sample** asset databases; no production
  customer data is shown.
- The guide is self-contained and works offline.
